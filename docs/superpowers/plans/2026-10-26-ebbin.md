# Ebbin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Ebbin Anki desktop add-on: live XP/combo/level/streak, dynamic daily challenge + missions, pomodoro, end-of-session pop-up, mastery metrics, objectives, Easy-interval cap, multi-file `.txt` import, synthesized coin sounds and a hand-drawn light/dark UI.

**Architecture:** All rules live in pure-Python modules under `ebbin/core/` (no `aqt`, no `anki` imports) operating on small dataclasses, unit-tested with pytest. `ebbin/data/` reads the collection (`anki` only, no `aqt`) and persists add-on state as JSON; it is integration-tested against throwaway collections. `ebbin/ui/` wires Anki GUI hooks to webviews whose HTML/CSS/JS live in `ebbin/web/` and are served through `mw.addonManager.setWebExports`.

**Tech Stack:** Python 3.13 (Anki 26.08.1 bundled), `anki`/`aqt` 26.8.1, Qt6 WebEngine, vanilla JS + inline SVG, Web Audio API, pytest, Node 20 (only to test the custom-scheduling JS).

**Spec:** `docs/design.md` (Portuguese). Approved mockups: `docs/mockups/session-summary-v2.html`, `docs/mockups/sounds-v2.html`, `docs/mockups/dark-mode.html`.

## Global Constraints

- **Never run `git commit`/`git push`** (user's global rule). The project is not a git repo; replace every "commit" with "leave changes in the working tree". Tasks end at "tests pass".
- Anki desktop ≥ 26.08 only; `manifest.json` `"min_point_version": 260800`. macOS is the primary target.
- UI language: pt-BR only. Copy in this plan is final unless marked *(placeholder)*.
- No network at runtime. Fonts (Caveat, Source Serif 4, OFL) are bundled as `.woff2` in `ebbin/web/fonts/`.
- No AI features.
- The add-on never changes card content/note-type templates.
- XP comes only from answering reviews; importing gives no XP.
- The user studies only on desktop: XP/combo/missions/sessions are recorded live; no sync reconciliation.
- Theme tokens (exact): light `paper #fbfaf6, ink #1f1f1f, muted #7a7a74, line #e3e1d9, terra #cf6f55, green #3f7d6a, hl #f7ddd4`; night "Caderno à noite" `#1d1c1a, #ece8df, #9a968c, #34322e, #e58a6f, #7fbfa6, #5a3a31`; slate "Quadro-negro" `#1f2a26, #eef0ea, #a7b3ac, #34433d, #f2a08a, #a8e0c8, #6b4a3f` + chalk texture filter.
- Anki day = scheduler day: day start ms = `(col.sched.day_cutoff - 86400) * 1000`; day index = `col.sched.today`. Never use calendar midnight.
- Dev environment: `.venv` created from Anki's bundled interpreter; never install anything into the user's Anki venv.

## Review Focus

1. **Undo after answering (Ctrl+Z):** XP, combo, mission progress and "rescued/mastered" credit for the undone answer disappear. Pinned in Task 2 (ledger keyed by revlog id) and Task 13 (undo hook reconciles).
2. **Reviews after midnight but before Anki's rollover (4 h):** they count for the previous Anki day (streak, missions, daily XP). Pinned in Task 4 and Task 5 tests.
3. **Brand-new/empty history:** no revlog rows → avg time 30 s, capacity 40, no division by zero, metrics show empty states. Pinned in Tasks 4, 6, 11.
4. **Malformed import file** (unknown note type, missing `#separator`, BOM, non-UTF-8, empty file): preview flags it, others still import, nothing crashes. Pinned in Task 10.
5. **User already has custom-scheduling code:** Ebbin's block is inserted between markers, re-install is idempotent, removal leaves the user's code byte-identical. Pinned in Task 9.

```js
// ebbin:start
(function () {
  const RATIO = __RATIO__, FIRST_MAX = __FIRST__;
  function rev(s) { return s && s.normal ? s.normal.review : (s && s.filtered && s.filtered.rescheduling ? s.filtered.rescheduling.originalState.review : null); }
  const g = rev(states.good), e = rev(states.easy);
  if (!e) return;
  if (g) { e.scheduledDays = Math.min(e.scheduledDays, Math.max(g.scheduledDays + 1, Math.round(g.scheduledDays * RATIO))); }
  else   { e.scheduledDays = Math.min(e.scheduledDays, FIRST_MAX); }
})();
// ebbin:end
```
